The GitHub social preview (1280x640). To re-render `social-preview.png` after editing `social-preview.html`, run `node -e "const{chromium}=require('@playwright/test');(async()=>{const b=await chromium.launch();const p=await b.newPage({viewport:{width:1280,height:640}});await p.goto('file://'+process.cwd()+'/docs/assets/social-preview/social-preview.html');await p.screenshot({path:'docs/assets/social-preview/social-preview.png'});await b.close()})()"` from the repo root, then upload it in Settings, General, Social preview.
