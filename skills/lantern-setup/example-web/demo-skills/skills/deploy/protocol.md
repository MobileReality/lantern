# Deploy protocol (for the delegate)

`SKILL.md` beside this file is the planner's; this one is yours.

1. Run `$D/scripts/preflight.mjs`. Any line it prints stops the rollout.
2. Work through [the checklist](references/checklist.md), item by item.
3. Roll out in stages. If a stage fails, run `scripts/rollback.sh <release>` and report.
